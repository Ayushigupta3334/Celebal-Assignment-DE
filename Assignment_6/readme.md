# Apache Spark Practice Topics

This repository contains practice questions and PySpark examples covering the core concepts of Apache Spark and DataFrame operations.

## 📚 Topics Covered

* Apache Spark Architecture
* Driver, Cluster Manager, and Executor
* Lazy Evaluation
* Lineage Graph (DAG) and Fault Tolerance
* Reading CSV Files
* CSV vs Parquet
* Predicate Pushdown
* DataFrame Operations

  * Selecting Columns
  * Filtering Data
  * Renaming Columns
  * Casting Data Types
  * Adding New Columns
* Transformations vs Actions
* Reading and Writing Parquet Files
* Client Mode vs Cluster Mode
* Logical Operators (AND & OR) in Filters
* Data Exploration using `.show()` vs `.collect()`

## 🛠️ Technologies Used

* Apache Spark
* PySpark
* Python
* DataFrames
* CSV & Parquet File Formats

## 🎯 Purpose

This repository is designed for learning, practicing, and revising Apache Spark fundamentals and PySpark DataFrame operations. It is suitable for beginners, students, and interview preparation.
