# Celebal Technologies Data Engineering Internship

## Overview

This repository contains the assignments, projects, and practical exercises completed during the Celebal Technologies Data Engineering Internship. The work covers various aspects of Data Engineering, SQL, Python, Data Analysis, ETL processes, and data management concepts.

The objective of this repository is to document the learning journey, showcase hands-on implementation of data engineering concepts, and maintain all internship deliverables in a structured manner.

## Repository Contents

The repository includes:

* Weekly internship assignments
* SQL practice and analysis projects
* Data cleaning and preprocessing tasks
* Data analysis projects
* ETL-related exercises
* Python-based data processing tasks
* Documentation and reports

## Technologies Used

* Python
* SQL
* SQLite
* PostgreSQL
* Pandas
* NumPy
* Jupyter Notebook
* Google Colab
* Git & GitHub

## Learning Areas

During the internship, the following concepts were explored:

* Database Management Systems
* SQL Queries and Optimization
* Data Cleaning and Transformation
* Exploratory Data Analysis (EDA)
* ETL Pipelines
* Data Warehousing Concepts
* Window Functions, CTEs, and Subqueries
* Data Visualization
* Version Control with GitHub

## Project Structure

Each assignment is organized into separate folders containing:

* Source code
* Notebooks
* Datasets (where permitted)
* Reports and documentation
* README files

## Purpose

The purpose of this repository is to maintain a centralized collection of internship work while demonstrating practical skills in data engineering and analytics. It serves as both a learning archive and a portfolio of completed assignments.
