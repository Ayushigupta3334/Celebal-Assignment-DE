# basic-data-exploration-cleaning-pandas
Basic data exploration and cleaning using Pandas on shopping datasets with pre-processing, missing value handling, filtering, and dataset analysis.

## Project Overview
This project demonstrates basic data exploration and cleaning techniques using the Pandas library in Python.

The **primary dataset** used for detailed analysis is **Combined_dataset.csv**, which contains multiple shopping product categories.

Additionally, **dresses.csv** was explored to practice data handling across different product categories and improve understanding of dataset diversity.

## Datasets Used

### Main Dataset
- Combined_dataset.csv

### Additional Practice Datasets
- dresses.csv

## Tasks Performed
- Data loading using Pandas
- Data exploration
- Missing value handling
- Row filtering
- Duplicate removal
- Derived column creation
- Exporting cleaned datasets
