# Mini Project Summary

## Problem Statement

Build a complete Azure Data Factory pipeline that reads a CSV file from Blob Storage, validates metadata, and copies data to a new location.

---

## Components Used

### Source

* CSV file stored in Azure Blob Storage.

### Linked Service

* Connection between ADF and Storage Account.

### Datasets

* Source Dataset
* Destination Dataset

### Activities

1. **Get Metadata**

   * Checked file existence
   * Retrieved file size
   * Retrieved last modified timestamp

2. **Copy Data**

   * Copied data from source CSV
   * Stored output in destination folder/file

---

## Workflow

```text
Source CSV
      │
      ▼
Get Metadata
      │
      ▼
Copy Data
      │
      ▼
Destination CSV
```

---

## Expected Output Achieved

✅ Pipeline executed successfully

✅ Metadata validated

✅ Data copied to destination

✅ Output file generated in Blob Storage

---

## Conclusion

An end-to-end Azure Data Factory ETL pipeline was successfully developed. The solution connected Azure Blob Storage through Linked Services, 
validated source file metadata using Get Metadata activity, copied data using Copy Data activity, and generated the output file in the destination
location with successful pipeline execution.
